لوحة التحكم — المستخدمين

تضيف وتعدّل وتحذف المستخدمين، وعند الحفظ ينحفظ التعديل في ملف users.json داخل مستودعك على GitHub.

كيف أجيب التوكن؟

  1. ادخل GitHub ← صورتك ← Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token.
  2. الاسم: أي اسم، والمدة: اختر ما تبي.
  3. في Repository access اختر Only select repositories ثم مستودعك فقط.
  4. في Permissions ← Repository permissions ← Contents ← اختر Read and write.
  5. اضغط Generate token وانسخه والصقه فوق. لا ترسله لأحد.
